# Imágenes de la Preboda

Coloca aquí las imágenes finales de la preboda de Stephanie & Daniel.

### Formatos Recomendados:
- **WebP:** Altamente recomendado para optimizar el rendimiento y velocidad en dispositivos móviles.
- **Nombres sugeridos:** `foto1.webp`, `foto2.webp`, etc., o nombres descriptivos.

### Cómo usarlas en el código:
Puedes hacer referencia a estas imágenes utilizando rutas absolutas relativas al directorio público, por ejemplo:
`"/images/preboda/foto1.webp"`
